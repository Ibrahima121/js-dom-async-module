# JS DOM Async Module

A collection of tasks for practising JavaScript, the DOM, and asynchronous programming.

## Tasks

### Interactive To-Do List

Location: `tasks/todo-interactive/`

A responsive to-do list built with HTML, CSS, and vanilla JavaScript.

**Features**
- Displays sample tasks.
- Click a task to toggle between incomplete and completed.
- Completed tasks turn green and reveal a check mark.
- Shows the number of completed tasks.
- Supports keyboard interaction with Enter and Space.

## Run locally

1. Clone or download this repository.
2. Open `tasks/todo-interactive/index.html` in a browser.
3. Click tasks to mark them complete or incomplete.

No dependencies or build tools are required.
